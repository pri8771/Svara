# Quality Evidence

Store small, durable evidence indexes here. Large logs, screenshots,
`.xcresult` bundles, videos, and traces should remain CI artifacts.

Each record identifies the feature, scenario, environment, date, result, and
artifact location.

Current durable indexes:

- `UI-WORKFLOW-AUDIT-2026-07-30.md` — comprehensive simulator workflow audit,
  failure classification, and local `.xcresult` locations.
- `TESTFLIGHT-READINESS-2026-07-29.md` — historical readiness baseline.
- `testflight/` — task-specific TestFlight evidence.
